## About the Project

**SugboKlaro** is a citizen-centered transparency and compliance checker that analyzes publicly disclosed LGU spending against applicable laws and regulations. This makes government data easier for ordinary citizens to understand and question.
SugboKlaro covers three of the fourteen document types required under the [DILG Full Disclosure Policy](https://fdpp.dilg.gov.ph).

This project is for Team M & 'Ems submission for the [**𝗖𝗮𝗻 𝗬𝗼𝘂 𝗛𝗮𝗰𝗸𝗜𝗧 2026: 𝗧𝗵𝗲 𝗜𝗕𝗣𝗔𝗣 𝗖𝗵𝗮𝗹𝗹𝗲𝗻𝗴𝗲 (𝗖𝗬𝗛)**](https://www.facebook.com/share/p/1MjZBosdbV/).

## How to Use

Using **SugboKlaro** is simple!
1. On the home page, projects and disclosures are presented. Click the 'Check' button to view its compliance results
2. Once you click the 'Check' button, an indicator on whether or not the disclosure has passed is displayed alongside its legal basis and an AI Overview to simplify the explanation
3. Go to the 'Reports' tab to view the list of reports
4. A chatbot named SKAI is provided for any additional questions

## Using the Program

### Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

### Project Setup

#### Clone the github repository
```sh
git clone https://github.com/RiceCell/SugboKlaro.git
```

#### Download the dependencies

```sh
npm install
```

#### Setup your .env file
./SugboKlaro/.env:
```
VITE_GEMINI_API_KEY=YOUR GEMINI API KEY
```
*Place your .env file in the same folder as App.vue*

#### Using the Python Engine
> Refer to the python_engine_README file

#### Compile and Hot-Reload for Development

```sh
npm run dev
```

or Compile and Minify for Production using:

```sh
npm run build
```
